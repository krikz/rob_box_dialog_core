# AGENTS.md — правила для AI-агентов в репо ядра

Это копия правил из `krikz/rob_box_project/AGENTS.md`, сокращённая для ядра (ADR-0167 §6). Полный текст, процесс
координатора и воркеров, ADR и словарь (`CONTEXT.md`) лежат там. Если правило меняется, его правят в обоих репо.

## Культура честности (АБСОЛЮТ)

- «Честный FAIL лучше красивого PASS» (ADR-0018). Не проверил — не пиши «работает». Не запускал тесты — не пиши «зелёные».
- В PR и комментариях к issue всегда прикладывай raw-вывод: `pytest -v`, `gh run view <run_id>`, `git log --stat`.
- Владелец — **товарищ Шифу**, старший воркер — **шисюн**, младший — **шиди**.

## Код решает, LLM говорит (ADR-0148)

Если LLM ошиблась на пути решения, решение переносят в код или сужают выбор структурой (схема тула, перечисление,
валидатор). Фразу об успехе строит код из результата. Временная заплатка помечается `TEMP(ADR-0148)` и получает карточку
на удаление.

## Как работать в этом репо

- Одна задача — одна ветка от свежего `origin/main` — один PR в `main`. Прямых push в `main` нет.
- Коммиты — Conventional Commits: `<type>(<scope>): <subject>`.
- Релиз — тег `vX.Y.Z` на `main` после зелёного CI. Ломка порта или формата профиля — мажорная версия.
  Подъём версии у робота или колонки — отдельный PR в их репо, там же живая проверка (ADR-0167 §3).
- Ядро не импортирует ROS на верхнем уровне и не читает файлы вне пакета. Данные ядра берутся через `importlib.resources`.
  Это сверяют `test_core_package_4245.py` и `test_core_package_boundary_0167.py`.
- Ключи провайдеров хранятся только в окружении или `.env` (в git не попадает). В репо их нет.

## Гарды до пуша

Зелёный pytest ещё не означает зелёный CI. Перед пушем прогони:

```bash
bash scripts/ci/core_guards.sh        # cc_budget, class_budget, TEMP(ADR-0148) по каталогам ядра
```

`seam_without_consumer.py` ищет потребителей шва во всём дереве робота, поэтому CI гоняет его после
`scripts/ci/robot_overlay.sh`.

## Код

- Python: `black` и `isort` (profile black, длина строки 120), `flake8`.
- Знание (лады, списки тулов, потолки) живёт в одном модуле, остальные его импортируют.
